### Other changes

- New `ook.services.guardedhttp` package, the single SSRF resolve-validate-pin implementation for fetching user-supplied URLs. `resolve_and_validate` resolves a host and refuses it unless every address it names is globally routable, raising distinct errors for a non-public host and for a host that does not resolve; `pinned_to` hands the validated address to the transport for one request through a context variable; and `create_guarded_client` builds an `httpx.AsyncClient` whose connection pool dials that address through a custom httpcore network backend, `PinningNetworkBackend`. A request made without a pinned address fails closed: the backend guards the host itself, logs a warning, and refuses to connect to a non-public address. Request URLs keep their hostname, so TLS SNI, certificate verification, and connection reuse all stay keyed by hostname. The link checker and the intersphinx inventory cache fetch through this guarded client. `httpcore` is now a direct dependency.
