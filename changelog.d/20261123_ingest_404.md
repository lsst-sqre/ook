### Bug fixes

- The `ook ingest-updated` job no longer fails when one LSST the Docs project cannot be found. A project can be registered in the LTD API while its published site returns a 404 (for example, a newly created technote that has not been published yet), and that single 404 used to abort the run before the remaining updated projects were queued. A 404 from the LTD API or from the project's published site now logs a warning and the run moves on to the next project; the completion log reports the number of skipped projects as `not_found`. `POST /ook/ingest/ltd` skips not-found projects the same way, and the Kafka ingest consumer logs a warning instead of raising when a queued document's site, LTD resources, or `metadata.yaml` return a 404. Other error statuses still fail as before.
