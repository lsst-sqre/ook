### Bug fixes

- The link checker no longer reports a working page as an HTTP 421 (Misdirected Request) when its host shares CDN addresses with another checked host, as docs.python.org and pypi.org do on Fastly. To guard against DNS rebinding, the checker rewrote each request's URL host to the validated IP address, which made the HTTP client reuse a connection opened for one hostname for another hostname at the same address; the CDN refused the request with a 421, or, on Cloudflare, with a 403 that the checker reported as `blocked`. The checker now fetches through the `ook.services.guardedhttp` guarded client, which pins each connection to the validated address at the socket layer while the request keeps its hostname, so a connection is only ever reused for the hostname it was opened for. A link-check failure for a host that does not resolve now names the host in its error detail.
