### Bug fixes

- The link checker now treats an HTTP 421 (Misdirected Request) as inconclusive, like a 429 or a 503: the URL is reported `blocked` with the error `HTTP 421 (misdirected request)`, and the result never advances or resets the failing-to-broken ladder. A 421 means a CDN edge refused the connection the request arrived on, not that the link is broken. A contributed result with status 421 is classified the same way. Ook's own checks and contributions now share one set of transient status codes.
- Link-check failure details now include the `via` and `x-served-by` headers when the response carries them, so failures served by a Fastly or other Varnish-based edge can be identified the same way Cloudflare's `server`, `cf-mitigated`, and `cf-ray` headers already identify Cloudflare.
