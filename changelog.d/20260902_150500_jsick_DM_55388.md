### New features

- New `/ook/intersphinx/sources` registry API naming the documentation sites Ook pulls Sphinx `objects.inv` inventories from. A registration is an inventory URL plus a human title (which surfaces as the `collection_title` of every link ingested from the site) and an `enabled` flag; `POST`, `GET` (single and list), `PATCH`, and `DELETE` are all supported, and `GET /ook/intersphinx/sources?enabled_only=true` narrows the listing to the sites the next ingest run will visit. The inventory URL is a registration's identity, so registering one that is already registered — or moving a registration onto another's URL — is a `409` rather than a second row, and an `http` URL is refused up front because the ingest path can only fetch over `https`. Each registration also reports when Ook last attempted to ingest it (`date_ingested`), how that attempt ended (`last_status`), and why it failed (`last_error`); those three are written by ingest runs and refused in a request body, so a registration cannot claim an outcome it never had. Writes are gated by the `exec:admin` scope at the Gafaelfawr ingress — not the `write:intersphinx` scope that warms the inventory cache — since registering a site commits Ook to serving links from it.
