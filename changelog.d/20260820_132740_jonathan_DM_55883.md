### Other changes

- Sped up the test suite roughly five-fold on CI. The test fixtures now start the application lifespan (including the Kafka consumer) once per pytest session instead of once per test, and reset the database between tests with a bounded, lock-diagnosing `TRUNCATE` instead of recreating the schema. The suite runs under pytest-xdist with four workers by default, with per-worker PostgreSQL databases and Kafka topic/consumer-group namespaces; pass `-n 0` to pytest for a serial run. Schema and migration tests now run against a dedicated database so DDL never contends with the shared application's connection pool.
- Restructured CI to run type checking and a new containers-free `test-unit` nox session as parallel jobs alongside the test job, and enabled uv dependency caching in all jobs. The `test-unit` session gives sub-second local feedback on tests that need no database or Kafka.
